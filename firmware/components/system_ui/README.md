# System UI

System-wide user interface independent of individual games.

First-level Quick Controls:
- Brightness
- Sound
- Dimming
- Language
- Clock & Date
- Screensaver
- Theme
- Information

Each item opens its own dedicated page. The main control page is deliberately not a dashboard containing every slider.

The system UI owns navigation and consumes the Settings, Input, Localization, Screensaver, Theme, Display, Audio, RTC and Version services.
